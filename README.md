# OOP1

Šis projektas yra C++ programa, skirta studentų pažymių įvedimui ir galutinio rezultato skaičiavimui.

## Funkcionalumas
- Įvedami studentų vardai ir pavardės.
- Įvedami pažymiai bei egzamino rezultatas.
- Apskaičiuojamas galutinis rezultatas pagal pažymių vidurkį ir (pasirinktinai) medianą.
- Išvedami suformatuoti rezultatai.
